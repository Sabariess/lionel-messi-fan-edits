# Messi Magic — Fan Edit Hub

A responsive, fan-made website for discovering Lionel Messi goals, skills, Argentina moments, and fan edits.

## Run locally

Open `index.html` in a browser. No build tools or dependencies are required.

## Video links

The cards open YouTube search results so viewers can find edits and watch them on the original platform. This site does not host copyrighted video content.

## Customize

Edit the cards in `index.html` to add new categories or searches. The built-in category filters and search field work with the `data-category` and `data-search` attributes.

This is an unofficial fan project and is not affiliated with Lionel Messi or any football club or league.
